# SEU 齿轮箱振动状态分类实验

使用 SEU 齿轮数据的 `30_2` 工况（30 Hz–2 V）开展健康、崩齿、缺齿、齿根故障、齿面故障五分类，比较随机森林与一维 CNN。按数据来源、实验背景、数据直观认识、处理和验证逐步开展。

- [原始数据](原始数据/SEU)：固定版本的 10 个 CSV 与原作者说明。
- [数据来源清单](原始数据/来源记录/数据来源清单.json)：当前路径、源版本及校验信息。
- [实验探索记录](工作目录/实验探索记录.md)：数据清点、依据和当前待核实项。
- [课程要求](工作目录/来源核查/课程要求.md)：课程要求与原始照片。

原始论文：[Highly Accurate Machine Fault Diagnosis Using Deep Transfer Learning](https://doi.org/10.1109/TII.2018.2864759)。

数据仓库：https://github.com/cathysiyu/Mechanical-datasets 。固定版本：9732a2820f4cdf91fa7d1d0cc95442376660f5dd。

当前观察行星齿轮箱第 2—4 通道的三轴振动，见 [数据直观认识](工作目录/当前笔记/SEU-数据直观认识.md)。故障安装部件继续按原始来源核实。旧代码、模型和报告保留在相邻的课程作业目录。
