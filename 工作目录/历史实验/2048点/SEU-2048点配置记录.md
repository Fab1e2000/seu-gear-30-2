# 2048 点配置记录

每个窗口 2048 点，随机森林和 CNN 共用分段和窗口位置。

两种方法分别输入：

- 随机森林：从窗口里算出的特征值。
- CNN：窗口里的原始振动波形。

## 随机森林模型配置

此方向需要考虑输入特征值和超参数的配置。


### 第一轮：候选输入

| 方案 | 特征 | 数量 | 比较目的 |
| --- | --- | --- | --- |
| A | x、z RMS | 2 | 先前观察到的重点特征 |
| B | 三轴 RMS | 3 | 验证 y 方向的补充作用 |
| C | 三轴各 8 个时域特征 | 24 | 验证能否改善齿面与缺齿的区分 |

8 个特征为均值、标准差、RMS、绝对峰值、峰峰值、偏度、峭度、峰值因子。标准差采用总体标准差，峭度采用普通峭度（正态参考值为 3），与前面的观察保持一致。

每个窗口对应一行特征，输出为五种状态之一。

### 第一轮：候选超参数

每组输入都尝试以下取值的全部组合，输入和超参数一起比较。

| 超参数 | 候选值 | 选择理由 |
| --- | --- | --- |
| 树的数量 | 200、500 | 比较增加树数是否带来收益 |
| 最大深度 | 4、8、不限制 | 覆盖较简单、中等及充分生长的树 |
| 叶节点最少样本数 | 1、3、8 | 比较细分与平滑效果 |
| 每次分叉可选特征数 | 特征数平方根向下取整、全部 | 比较随机选取特征和使用全部特征 |

这些取值作为第一轮搜索范围。A、B 的平方根方案每次可选 1 个特征，C 可选 4 个；全部特征分别为 2、3、24 个。

固定随机种子 42，使用 Gini 作为不纯度判断指标、有放回抽样，类别权重不调整（各类窗口数相同）。种子用于复现，不参与择优。

每种输入 2×3×3×2＝36 套参数，三种输入共 **108 套配置**。每套做三折时间交叉验证，共 **324 次森林训练**。按三折宏平均 F1 的均值比较，同时看各折波动和齿面／缺齿的混淆情况。测试集留到最终配置确定后使用。

完整候选组合见 [配置清单](../../configs/seu_30_2_rf_candidates.json)。候选已在 Windows 主机完成三折验证，见 [训练记录](SEU-随机森林训练.md)。

参数含义参考 [RandomForestClassifier 官方文档](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.RandomForestClassifier.html)，时间划分参考 [TimeSeriesSplit](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)。

### 第二轮：扩大搜索

第一轮 A、B 都偏好叶节点最少 8 个样本，已到候选上限；C 在深度 8 附近表现较好。这次把范围放宽，也补几组输入看看。

| 方案 | 特征 | 数量 |
| --- | --- | --- |
| A | x、z RMS | 2 |
| B | 三轴 RMS | 3 |
| C | 三轴各 8 个时域特征 | 24 |
| D | 三轴标准差 | 3 |
| E | 三轴 RMS、峭度、峰值因子 | 9 |
| F | C 去掉均值、标准差 | 18 |

D 看标准差替换 RMS 的效果；E 看冲击相关特征有没有补充作用；F 看去掉均值和重复信息后表现如何。

| 超参数 | 候选值 |
| --- | --- |
| 树数 | 200、500、1000 |
| 最大深度 | 4、6、8、12、20、不限制 |
| 叶节点最少样本数 | 1、2、3、5、8、16 |
| 每次分叉候选特征数 | 特征数平方根、一半、全部；向下取整后去重 |

A、B、D 各 216 套，C、E、F 各 324 套，共 **1620 套配置、4860 次训练**。完整网格包含第一轮全部配置，统一重新计算。

仍用三折时间验证、2048 点窗口、种子 42，其他固定参数沿用第一轮。按三折宏平均 F1 的均值比较，同时看各折波动和齿面／缺齿的混淆。测试段继续封存。

配置见 [扩展清单](../../configs/seu_30_2_rf_expanded.json)，进度见 [训练记录](SEU-随机森林训练.md)。

第二轮已完成，六组成绩和最佳参数见 [扩大搜索结果](SEU-随机森林扩大搜索.md)。

### 阶段结论

完整 24 特征的 C 组最好，三折宏 F1 为 0.9272。扩大调参仅比第一轮提高约 0.0007，当前优先保留完整特征。

建议后续配置：1000 棵树、最大深度 20、叶节点最少 1 个样本、分叉候选 4 个特征、种子 42。最终训练与测试待下一步进行，结论见 [扩大搜索结果](SEU-随机森林扩大搜索.md)。
