# 实验探索记录

## 数据来源与研究范围

核对作者仓库、原论文和本地文件，选用 SEU 齿轮数据的 `30_2` 工况（30 Hz–2 V），观察行星箱 x、y、z 三轴（第 2—4 通道），研究五类状态。

原论文图 8 为 DDS 试验台照片，见 [原论文图页](来源核查/原论文图页/page-07.png)。

试验台包含行星齿轮箱和平行轴齿轮箱。按导师指定，暂以太阳轮故障作为研究假设；原论文未明确具体故障安装部件。

来源：[作者仓库](https://github.com/cathysiyu/Mechanical-datasets) · [原论文](来源核查/SEU-原始论文-Shao-2019.pdf) · [数据清单](../原始数据/来源记录/数据来源清单.json)

## 数据直观认识

| 内容 | 观察 |
| --- | --- |
| 五种状态的完整三轴波形 | 健康振动带较宽，齿面故障有突出尖峰 |
| 三轴八项整段时域特征 | 健康 RMS、标准差最高；齿面故障峰值、峰峰值、峰值因子最高 |
| 每文件切成 100 个不重叠窗口，每窗 10,485 点，末尾 60 点不用 | 健康和齿部故障在标准差、RMS 上较容易分开，尤其是 x、y 方向；其余故障有重叠 |
| 开头与中段对照：前 20 窗和第 51—70 窗 | 开头均值下降，z 方向最明显；对应运行阶段待核实 |
| 三轴 RMS 与峭度散点图，每种状态每轴 100 个点 | 健康三轴点群独立；齿部故障在 x、y 方向较清楚，其余三类仍有重叠 |
| x—z、y—z RMS 和同方向 RMS—峰值因子 | 跨方向 RMS 让齿根和齿面故障分得更清楚；缺齿与齿面故障局部重叠；峰值因子突出少量尖峰窗口 |
| 24 项特征的 276 种双组合及前后半段 | x—z RMS 优先保留；x 均值＋z RMS 也是候选，齿面故障均值后半段上移；同轴 RMS 和标准差高度重复；x 峭度＋z RMS 改善很小 |

## 当前进展

当前固定 8192 点窗，不重叠。前四个时间块做三折验证，训练窗口数为 125／250／375，验证均为 125。三组输入的 108 套配置已完成调参：三轴 RMS 0.9814，24 特征 0.9893，xz RMS 0.9578。

## 采样率与转频

对五种状态三轴做了低频功率谱，均出现约 30、60、90 Hz 的峰。结合文献和导师决定，后续采用采样率 **5120 Hz**、输入轴转频 **30 Hz**（1800 转/分钟）作为工作设定。8192 点对应 1.6 秒、约 48 转。

## 2026-11-10：CNN 时间间隔验证方案

问题：固定 CNN023 后，训练与评价的时间距离增大会否降低分类表现？

设计：仅使用开发侧 B1—B4，固定 B1 的 510 个不重叠窗口训练，分别评价 B2、B3、B4，各 510 窗。训练侧使用到第 208896 个采样点，至三个评价段的实际间隔分别为 816、210528、420240 点；按工作设定 5120 Hz，约为 0.159、41.119、82.078 秒。固定种子 42、7、2026、CNN023 配置和此前开发侧确定的 62 轮，每个种子仅训练一个模型，三个评价段共享同一模型。标准化仅拟合实际训练窗口。记录训练与评价交叉熵、准确率、宏 F1、混淆矩阵及逐窗概率，不据本次分数重新选轮数或参数，不加载 B5。

解释范围：训练量保持相同，时间距离与评价段位置一起改变；下降时需结合时间漂移分析。三个种子用于观察优化随机性，窗口来自同次记录。本实验属于已用于模型选择的开发数据上的敏感性分析。

执行脚本：`scripts/validate_seu_cnn_gap.py`，复用 `train_seu_cnn.py` 的模型。运行环境位于 Windows 的 `D:\SEU-training-20261104\.venv`。

## 2026-11-10：CNN 时间间隔验证完成

Windows 使用原虚拟环境完成三个种子训练，输出已取回 `outputs/SEU-CNN时间间隔验证/`。逐项从混淆矩阵复算准确率、宏 F1 和错误数，全部一致。

| 数据段 | 三种子平均准确率 | 平均宏 F1 | 平均交叉熵 | 各种子错误数（42 / 7 / 2026） |
| --- | --- | --- | --- | --- |
| B1 | 100.0000% | 1.000000 | 0.003397 | 0 / 0 / 0 |
| B2 | 99.4118% | 0.994120 | 0.015681 | 3 / 4 / 2 |
| B3 | 99.4118% | 0.994127 | 0.016067 | 5 / 2 / 2 |
| B4 | 98.7582% | 0.987630 | 0.025264 | 5 / 8 / 6 |

发现：B2 至 B4 平均准确率下降约 0.65 个百分点；三个种子的 B4 准确率均低于 B2，交叉熵均升高。远段仍达到 98.43%—99.02%。B4 的错误主要集中于缺齿、齿根，缺齿误判齿面分别为 3、5、4 窗。训练段均为 100%。

判断：同记录内时间距离增大伴随小幅性能退化，模型仍保持较高分类能力。证据支持存在一定时间敏感性，尚待区分时间漂移、具体段落难度和模型拟合因素。间隔与评价段位置同时变化，三个种子共享评价窗口，结果按开发侧敏感性分析解读；此前已使用这些开发段选择配置和训练轮数。

后续建议：优先比较 B1—B4 中缺齿、齿根与齿面的三轴 RMS、均值及错误窗口位置，定位远段变化。随后按讨论开展逐窗归一化消融，观察幅值信息作用；当前不追加调参或模型改动。

## 2026-11-10：过拟合诊断补充实验预设

沿用 B1 训练、B2/B3/B4 评价和三个种子。运行前固定四组：CNN023 基线、逐窗逐轴去均值并除以标准差、通道缩小为 8→16→32、Adam 权重衰减 1e-4。各组同时保存固定 62 轮和仅由 B2 交叉熵选择的早停模型（最多 100 轮，耐心 15 轮）。早停触发后冻结其模型选择；为取得固定轮数对照，必要时继续至 62 轮。B3、B4 不参与选轮数。本轮比较用于诊断与开发，不声称新增独立测试。记录各窗口均值、RMS、标准差以及错误位置。完成后按证据决定是否保留现有模型或建议改动。

## 2026-11-10：过拟合诊断完成与报告准备

四组、三个种子共 12 次 Windows 训练已完成，保存固定 62 轮及 B2 选轮两种检查点。96 份预测结果逐项复算通过，基线固定 62 轮与此前时间间隔实验的预测复现一致。B3、B4 未参与早停，本轮未读取 B5。

主要结果：B4 平均准确率由基线固定 62 轮的 98.7582% 提升至 B2 选轮的 99.3464%；小模型 B2 选轮达到 99.7386%，参数由 44,773 降为 11,509。逐窗归一化 B2 选轮为 99.3464%，权重衰减 1e-4 为 99.0196%。基线最佳轮次 81/71/97，说明当前 B1 训练设置在 62 轮后仍有改善空间；seed=42 在 81→96 轮训练损失下降、验证损失上升，后期过拟合证据同时存在。

错误诊断：缺齿第 29、48 窗和齿根第 59 窗在三个基线种子中重复出错，错误跨越多个位置。三类主要难分类状态的平均 RMS 随块变化约在百分之几以内，部分轴的均值偏置变化较明显。逐窗去掉均值与幅值尺度后分类仍较好，未发现统一的幅值消融优势。保留原始标签和全部难例。

决定：保留 CNN023 主实验与原正式模型；报告补充 B2 验证选轮的实测改善，将小模型作为轻量化候选，完整呈现各段排名差异。当前结束开发侧调参，避免围绕已查看的 B4 继续选择方案。已经具备数据、方法、主实验、消融、学习曲线、错误分析和范围说明，可进入课程报告撰写。独立记录、试件和跨工况评价列为后续研究。
